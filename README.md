# vfox-eza

[eza](https://github.com/eza-community/eza) plugin for [mise](https://mise.jdx.dev) and [vfox](https://vfox.dev).

Where available, the plugin installs official prebuilt binaries published by
[eza](https://github.com/eza-community/eza). On platforms without official
binaries, such as macOS and Windows ARM64, it uses
[cargo-quickinstall](https://github.com/cargo-bins/cargo-quickinstall).

```sh
mise use -g vfox:jdx/vfox-eza@latest
```
